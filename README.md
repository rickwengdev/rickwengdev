## `01` &nbsp;//&nbsp; Now building

### [Saturn MCP](https://saturn-core.com/mcp) &nbsp;·&nbsp; the gateway

A gateway that governs what AI agents may do. Every tool call is checked against versioned
policy down to its arguments, sensitive calls are routed for human approval, and every
decision is recorded.

```text
   +-----------+        +-------------------------------------+        +-----------+
   |           |  call  |             SATURN  MCP             |  pass  |           |
   |   AGENT   | -----> |  [1] policy    argument-level check | -----> |   TOOLS   |
   |           |        |  [2] approval  human in the loop    |        |           |
   +-----------+        |  [3] audit     every decision kept  |        +-----------+
                        +------------------+------------------+
                                           |
                                           v
                     ######################################################
                     #  post-quantum credential vault                     #
                     #  audit payloads encrypted on archival              #
                     #  -> unreadable even to the gateway itself          #
                     ######################################################
```

### [Saturn App](https://github.com/Saturn-Technology-Project/Saturn-App) &nbsp;·&nbsp; the workbench

An open-source (Apache 2.0) desktop workbench for AI research. Experiments are compared only
when measured identically, every sample from every model can be inspected, and activation
patching and SAE feature analysis are built in. Each release ships with a checksum and signed
build provenance.
